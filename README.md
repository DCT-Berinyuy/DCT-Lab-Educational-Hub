## Repository Contents

This repository contains educational materials and programming exercises for GCE Advanced Level Computer Science students in Cameroon. It includes implementations of classic computer science problems and exercises that align with the GCE Advanced Level Computer Science curriculum.

### Current Projects

#### 1. AL-2025-CSC-3: Conway's Game of Life
Implementation of Conway's Game of Life cellular automaton in C - a complete solution to a Section B Programming Task from the GCE AL CSC-3 2025 syllabus.

#### 2. Algorithm-Mastery-Series-pseudocode-C-programs
Collection of algorithm exercises with both pseudocode and C implementations (Ex_1 through Ex_10) demonstrating fundamental programming concepts.

#### 3. CSC-P3-June-2021-Section-A-Programming-Solution
Solution to Section A Programming Task from June 2021 GCE exam - Implementation of Pascal's Triangle in C with detailed algorithm explanations.

## Purpose

This repository serves as a living collection of educational materials that will continue to grow with more lessons, exercises, and programming examples. It's designed to help students master programming concepts and prepare for their GCE Advanced Level Computer Science examinations.

## Contributing

As this is an educational repository for students, contributions come in the form of student engagement, practice, and feedback. Students are encouraged to study the examples, practice the algorithms, and apply the concepts to their own programming challenges.
